Skin tone detection from a photo

Upload or take a photo. The front end sends it to the image-processing back end, which finds the skin pixels, works out the dominant skin colour and classifies it with the Individual Typology Angle (ITA), a standard skin colour measure. The result comes back as JSON and is shown below.

How the back end gets the answer

The same steps run in the Python package skintone (used by the Django API) and in skintone.js (used on this page).

1 · Area

The API crops to the face found by OpenCV's Haar cascade. Here, the area you select (or the whole photo) is used.

2 · Skin mask

Shown in colour: pixels whose colour falls inside skin ranges in both HSV and YCrCb, after a 3×3 blur and a morphological opening to remove specks.

3 · Dominant colour

k-means (k = 3) groups the skin pixels in CIELAB colour space; the largest group is the skin colour; the others pick up shadows, highlights and skin-coloured clothing or background.

4 · ITA and category

ITA = arctan((L* − 50) / b*)

Above 55° Very light · 41–55° Light · 28–41° Intermediate · 10–28° Tan · −30–10° Brown · below −30° Dark.

Architecture

original_site/   front end (HTML, CSS, JavaScript)
                 upload page sends the photo to the API
api/             Django + Django REST Framework
                 POST /image-process -> JSON
skintone/        Python image-processing package
                 OpenCV face detection, NumPy pipeline
web/             this page; skintone.js is the same
                 pipeline in JavaScript for GitHub Pages
tests/           pytest, API tests, Python vs JS check

Run the real API locally (python api/manage.py runserver) and open this page with ?api=http://127.0.0.1:8000/image-process to send photos to Django instead.

ToneScan estimates the colour of skin in a photo. Lighting, white balance, filters and make-up change the result, and it is not a medical or cosmetic diagnosis tool. Reference colours in the tests: Monk Skin Tone Scale (Google, CC BY 4.0).
